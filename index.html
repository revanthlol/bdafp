Execution steps

  1. Create datasets: Paste the data files script into your Bash terminal once. It creates data1.txt and data2.txt in the current directory.
  2. Launch the shell: Run pig -x local for Pig programs or hive for Hive programs.
    Launch Pig 
    pig -x local
    Launch Hive 
    hive
  3. Execute code: Copy a program below, paste it at the matching grunt> or hive> prompt, and press Enter.

JOIN

Join the two files on id.

Input: data1.txt, data2.txt

Pig 
student = LOAD 'data1.txt' USING PigStorage(',')
    AS (id:int, name:chararray, age:int, city:chararray, m1:int, m2:int, m3:int);
emp = LOAD 'data2.txt' USING PigStorage(',')
    AS (id:int, name:chararray, dept:chararray, city:chararray, salary:int, year:int, temp:int, quality:int);
inner_join = JOIN student BY id , emp BY id;
DUMP inner_join;
left_join = JOIN student BY id LEFT OUTER, emp BY id;
DUMP left_join;
right_join = JOIN student BY id RIGHT OUTER, emp BY id;
DUMP right_join;
full_join = JOIN student BY id FULL OUTER, emp BY id;
DUMP full_join;
student_copy = FOREACH student GENERATE *;
self_join = JOIN student BY id, student_copy BY id;
DUMP self_join;

Shown: inner join. Student 4 and employee 5 demonstrate unmatched outer-join records.

Student Marks Analysis

Calculate total, average, pass/fail, topper and pass/fail counts.

Input: data1.txt

Pig 
student = LOAD 'data1.txt' USING PigStorage(',')
    AS (id:int, name:chararray, age:int, city:chararray, m1:int, m2:int, m3:int);
result = FOREACH student GENERATE id, name, (m1 + m2 + m3) AS total,
    (m1 + m2 + m3) / 3.0 AS average,
    ((m1 + m2 + m3) / 3.0 >= 40 ? 'Pass' : 'Fail') AS status;
DUMP result;
ranked = ORDER result BY total DESC;
topper = LIMIT ranked 1;
DUMP topper;
grouped = GROUP result BY status;
summary = FOREACH grouped GENERATE group, COUNT(result);
DUMP summary;

Pass/fail uses average >= 40, as in the record.

(4,neha,240,80.0,Pass)

Word Count

Tokenize names and cities, then count repeated words.

Input: data1.txt

Pig 
student = LOAD 'data1.txt' USING PigStorage(',')
    AS (id:int, name:chararray, age:int, city:chararray, m1:int, m2:int, m3:int);
lines = FOREACH student GENERATE CONCAT(name, CONCAT(' ', city)) AS line;
words = FOREACH lines GENERATE FLATTEN(TOKENIZE(line)) AS word;
grouped = GROUP words BY word;
counts = FOREACH grouped GENERATE group, COUNT(words);
DUMP counts;
