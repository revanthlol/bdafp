JOIN

Match customer IDs to order IDs.

Input files customers.txt, orders.txt
Terminal
cat > customers.txt <<'EOF'
1,Ramesh,32,Ahmedabad,2000.00
2,Khilan,25,Delhi,1500.00
3,Koushik,23,Kota,2000.00
4,chaitali,25,mumbai,6500.00
5,hardik,27,bhopal,8500.00
6,komal,22,mp,4500.00
EOF
Terminal
cat > orders.txt <<'EOF'
101,1,Laptop
102,2,Mobile
103,3,TV
104,5,Watch
105,7,Camera
EOF
Pig
customer = LOAD 'customers.txt' USING PigStorage(',')
    AS (id:int, name:chararray, age:int, place:chararray, amount:float);
orders = LOAD 'orders.txt' USING PigStorage(',')
    AS (orderid:int, id:int, product:chararray);
inner_join = JOIN customer BY id, orders BY id;
DUMP inner_join;

left_join = JOIN customer BY id LEFT OUTER, orders BY id;
DUMP left_join;

right_join = JOIN customer BY id RIGHT OUTER, orders BY id;
DUMP right_join;

full_join = JOIN customer BY id FULL OUTER, orders BY id;
DUMP full_join;

customer_copy = FOREACH customer GENERATE *;
self_join = JOIN customer BY id, customer_copy BY id;
DUMP self_join;

Outer joins keep unmatched rows with null fields. A self join uses two relation aliases.

Expected output

Inner join

(1,Ramesh,32,Ahmedabad,2000.0,101,1,Laptop)
(2,Khilan,25,Delhi,1500.0,102,2,Mobile)
(3,Koushik,23,Kota,2000.0,103,3,TV)
(5,hardik,27,bhopal,8500.0,104,5,Watch)

Maximum Temperature

Filter invalid readings, then find the maximum temperature per year.

Input files sample.txt
Terminal
cat > sample.txt <<'EOF'
1950,0,1
1950,22,1
1950,-11,1
1949,48,1
1949,42,1
EOF
Pig
records = LOAD 'sample.txt' USING PigStorage(',')
    AS (year:chararray, temperature:int, quality:int);
valid = FILTER records BY temperature != 9999 AND
    (quality == 0 OR quality == 1 OR quality == 4 OR quality == 5 OR quality == 9);
grouped = GROUP valid BY year;
max_temp = FOREACH grouped GENERATE group, MAX(valid.temperature);
DUMP max_temp;
Expected output

DUMP max_temp

(1949,48)
(1950,22)

Maximum Salary by City

Return the highest-paid employee records in each city.

Input files empdata.txt
Terminal
cat > empdata.txt <<'EOF'
03 Amit Delhi India 12000
04 Anil Delhi India 15000
05 Deepak Delhi India 34000
06 Fahed Agra India 45000
07 Ravi Patna India 98777
08 Avinash Punjab India 120000
09 Saajan Punjab India 54000
001 Harit Delhi India 20000
002 Hardy Agra India 20000
EOF
Pig
employees = LOAD 'empdata.txt' USING PigStorage(' ')
    AS (eno:int, name:chararray, city:chararray, country:chararray, salary:int);
grouped = GROUP employees BY city;
maxima = FOREACH grouped GENERATE group AS city, MAX(employees.salary) AS salary;
matched = JOIN employees BY (city, salary), maxima BY (city, salary);
result = FOREACH matched GENERATE employees::eno, employees::name,
    employees::city, employees::country, employees::salary;
DUMP result;

Matching both city and salary avoids cross-city matches. Ties keep all highest-paid employees.

Expected output

DUMP result

(5,Deepak,Delhi,India,34000)
(6,Fahed,Agra,India,45000)
(7,Ravi,Patna,India,98777)
(8,Avinash,Punjab,India,120000)

Filter high salaries, summarize departments and find the top three.

Pig
emp = LOAD 'emp.txt' USING PigStorage(',') AS (id:int, name:chararray, dept:chararray, salary:int);

sorted = ORDER emp BY salary DESC;
top3 = LIMIT sorted 3;

Student Marks Analysis

Calculate total, average, pass/fail, topper and pass/fail counts.

Input files stud.txt
Terminal
cat > stud.txt <<'EOF'
1,Amit,78,85,90
2,Neha,35,40,30
3,Rohan,60,55,70
EOF
Pig
stud = LOAD 'stud.txt' USING PigStorage(',') AS (id:int, name:chararray, m1:int, m2:int, m3:int);
result = FOREACH stud GENERATE id, name, (m1+m2+m3) AS total, (m1+m2+m3)/3.0 AS avg, (((m1+m2+m3)/3.0) >= 40.0 ? 'Pass' : 'Fail') AS status;
DUMP result;
ranked = ORDER result BY total DESC;
topper = LIMIT ranked 1;
DUMP topper;
grp = GROUP result BY status;
summary = FOREACH grp GENERATE group AS status, COUNT(result) AS students;
DUMP summary;

Pass/fail follows the record’s average >= 40 rule, not a per-subject pass rule.

Word Count

Extra program from the old cheatsheet and the record.

Input files words.txt
Terminal
cat > words.txt <<'EOF'
betty bought a butter but the butter was bitter so betty bought a better butter
EOF
Pig
lines = LOAD 'words.txt' USING PigStorage('\t')
    AS (line:chararray);
words = FOREACH lines GENERATE FLATTEN(TOKENIZE(line)) AS word;
grouped = GROUP words BY word;
counts = FOREACH grouped GENERATE group, COUNT(words);
DUMP counts;
